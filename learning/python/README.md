# Fundamentos de Python | Alura

## Sobre o projeto

Este repositório reúne exercícios práticos desenvolvidos durante meus estudos de Python na plataforma Alura.

O objetivo das atividades foi conhecer os fundamentos da linguagem, praticar a escrita de código e compreender como utilizar estruturas básicas para receber, armazenar, processar e exibir informações.

## Conteúdos praticados

### 1. Entrada e saída de dados
- Utilização de `input()` para receber informações.
- Exibição de mensagens com `print()`.
- Interação básica com o usuário pelo terminal.

### 2. Variáveis e manipulação de dados
- Declaração e atribuição de variáveis.
- Utilização de strings e números inteiros.
- Organização e apresentação de informações.

### 3. Formatação de strings
Prática com diferentes métodos de formatação:

- `f-string`
- `.format()`
- Operador `%`

### 4. Operações matemáticas
- Utilização de números decimais.
- Formatação de casas decimais.
- Arredondamento com `round()`.

### 5. Menus interativos
- Apresentação de opções no terminal.
- Recebimento da opção escolhida pelo usuário.
- Exibição da escolha realizada.

## Tecnologias utilizadas

- Python 3
- Visual Studio Code
- Alura

## Como executar

1. Instale o Python 3.
2. Clone ou baixe este repositório.
3. Abra a pasta no Visual Studio Code.
4. Execute o arquivo:

```bash
python exercicios_aula.py
```

## Objetivo de aprendizagem

Consolidar os conceitos fundamentais de Python como base para estudos posteriores em análise de dados, automação e desenvolvimento de aplicações.
